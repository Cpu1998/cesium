## 1. 初始化 Viewer（或只用引擎层）

**目标**：页面里出现一个地球，知道每个 options 落到源码哪里。

```js
const viewer = new Cesium.Viewer("cesiumContainer", {
  animation: false,        // 时间轴动画控件
  baseLayerPicker: false,  // 底图选择器（生产常关）
  requestRenderMode: true, // 按需渲染，省电省 CPU
});
```

深入：[01-Viewer创建与场景初始化.md](01-Viewer创建与场景初始化.md) §1（参数校验的关键决策）/ §4（`new CesiumWidget` 重头戏）/ §8（options 落点速查表）；构造器本体在 [`Viewer.js`](../packages/widgets/Source/Viewer/Viewer.js#L448)（注意 1.145 起 Viewer 在 `@cesium/widgets` 包）；`requestRenderMode` 的消费端是 [`Scene`](../packages/engine/Source/Scene/Scene.js#L125) 构造参数，帧旅程见 05 §4。

## 2. 换底图 / 叠加影像图层

**目标**：默认 Ion 影像换成自己的 XYZ/Tianditu/WMS，多层叠加调透明度。

```js
const layer = viewer.imageryLayers.addImageryProvider(
  new Cesium.UrlTemplateImageryProvider({
    url: "https://tile.example.com/{z}/{x}/{y}.png",
    maximumLevel: 18,
  })
);
layer.alpha = 0.7;       // 透明度
layer.brightness = 1.2;  // 调色
```

## 3. 加载 3D Tiles 与调 LOD

**目标**：加载大模型瓦片集，控制加载内存与清晰度。

```js
const tileset = await Cesium.Cesium3DTileset.fromUrl(url, {
  maximumScreenSpaceError: 16, // 越大越糊越省
  cacheBytes: 512 * 1024 * 1024,
  maximumCacheOverflowBytes: 256 * 1024 * 1024,
});
viewer.scene.primitives.add(tileset);
await viewer.zoomTo(tileset);
```

深入：[04-3DTiles加载与LOD.md](04-3DTiles加载与LOD.md) §3（每帧遍历怎么决定画哪几片）/ §7（cacheBytes 淘汰）/ §9（options 速查），入口 [`Cesium3DTileset.fromUrl`](../packages/engine/Source/Scene/Cesium3DTileset.js#L2287)、缓存上限 [`cacheBytes`](../packages/engine/Source/Scene/Cesium3DTileset.js#L1641)；内存三本账与跳级加载见 16 §7。

## 4. 加载 glTF 模型与播放动画

**目标**：往场景放一个 glTF/GLB，播放骨骼/节点动画。

```js
  url: "./car.glb",
  scale: 2.0,
});
viewer.scene.primitives.add(model);
// fromGltfAsync 的 Promise 决议时模型已就绪，直接加动画

```
